# StageHub

Учебное веб-приложение для учёта проектов сценического освещения. Реализовано на Flask, Jinja2, SQLite, Flask-SQLAlchemy и Flask-Login.

## Возможности

- Регистрация и вход по имени пользователя или электронной почте.
- Проверка уже зарегистрированных имён и адресов электронной почты.
- Хеширование паролей с помощью Werkzeug. Исходные пароли не сохраняются.
- Выход из аккаунта.
- Создание, просмотр и удаление проектов освещения.
- Пользователь видит и изменяет только собственные проекты.
- HTML-шаблоны Jinja2 и общий шаблон `base.html`.
- SQLite создаётся автоматически при первом запуске.

## Требования

Python 3.10 или новее.

## Запуск на macOS / Linux

Откройте терминал в папке проекта и выполните:

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python app.py
```

На Windows активация виртуального окружения:

```powershell
py -m venv .venv
.venv\Scripts\Activate.ps1
pip install -r requirements.txt
python app.py
```

Откройте в браузере адрес http://127.0.0.1:5000

Остановка сервера: `Ctrl+C`.

## Как проверить работу

1. Откройте сайт и нажмите «Регистрация».
2. Создайте аккаунт с паролем длиной не менее 8 символов.
3. Выйдите из аккаунта и войдите снова.
4. Попробуйте зарегистрировать то же имя пользователя или ту же электронную почту: приложение покажет ошибку.
5. Создайте проект, например «Worship Night», укажите площадку, описание и оборудование.
6. Откройте проект из списка и удалите его.
7. Зарегистрируйте второй аккаунт и убедитесь, что проекты первого пользователя ему не видны.

## Как устроена база данных

Таблица `user` хранит уникальные имя пользователя и email, а также поле `password_hash`. Пароль преобразуется функцией `generate_password_hash`; при входе используется `check_password_hash`.

Таблица `project` хранит данные проекта и `user_id`, который связан с пользователем через внешний ключ. Все запросы проектов фильтруются по `current_user.id`, поэтому нельзя открыть или удалить чужой проект, просто подставив другой идентификатор в URL.

## Важное замечание

Это учебный проект. Перед публикацией в интернете задайте уникальный секретный ключ через переменную окружения `SECRET_KEY`, отключите `debug=True`, включите HTTPS и добавьте защиту форм CSRF (например, Flask-WTF).
